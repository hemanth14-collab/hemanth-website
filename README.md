# Sai Hemanth Tiruvuri · pitch page

Static one-page site (plain HTML/CSS, no build step).

Publish on GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`.

Live at https://hemanth14-collab.github.io/hemanth-website/

Video cards play YouTube inline on tap; the viewership dashboard embeds live on wide screens and on tap elsewhere.

When you replace the photo or edit `style.css`, bump the `-v1` file name or the `?v=` query string in `index.html` so phones don't keep an old cached copy.
